# bug

## Job

תקן את הבאג שמתואר ב-issue. קרא את גוף ה-issue, הבן מה הבעיה, מצא את הקוד הרלוונטי, והחל את התיקון ב-PR.

## Allowed Commands

- קרא קבצים ב-repo
- ערוך קבצים
- פתח PR עם התיקון

## Restrictions

- תקן רק את מה שמתואר ב-issue — לא להוסיף פיצ'רים חדשים
- אל תיגע בקבצים שלא קשורים לבאג
- PR חייב לעבור CI לפני שמתקנים
